## 项目简介

《爆浆奶茶店》是一款以规则怪谈为叙事框架的 Unity 单机游戏 Demo。作品将文字冒险解谜作为主玩法，并结合模拟经营、箱庭解谜和快速反应事件：玩家从奶茶店的日常工作开始，在轻松的经营节奏与逐渐升级的压迫感之间切换，逐步发现店铺背后的秘密，并在不同选择中面对后果。

作品希望建立一种反差体验——表面上是熟悉的奶茶店工作，叙事和玩法却不断提示玩家：这里的“日常”并不安全。

## 我的作用

这是一个 4 人团队项目，我担任主程序，负责全部程序模块的开发、调试与整合。团队其他成员分别负责程序、策划和文案。

我的工作主要包括：

- 使用 Unity 实现并整合游戏的程序系统；
- 支持 Excel 驱动的剧情读取、剧情跳转、分支选择和多结局流程；
- 实现角色显示与状态、对话表现、场景切换、音频、存档/读档等运行时功能；
- 接入模拟经营与奶茶制作相关的小游戏流程，并处理小游戏成功、失败和特殊结果对应的剧情跳转；
- 为策划和文案开发剧情关系可视化工具 CanvasTool，辅助检查和维护复杂的剧情结构。

项目集中开发约 1 个月，使用 Unity 完成。

## CanvasTool：为剧情协作开发的工具

随着剧情拆分为多个 Excel 文件，`goto`、`choice` 和小游戏结果之间的跳转关系很难通过文件列表直接理解。为降低维护剧情树的负担，我另行开发了 CanvasTool：一个基于 Electron 的 Windows 桌面工具。

CanvasTool 会递归扫描剧情目录，解析 Excel 中的剧情指令，并生成可交互的关系图。工具支持：

- 将剧情文件、小游戏节点和缺失目标显示为不同类型的节点；
- 区分普通跳转、分支选择、进入小游戏和小游戏结果等关系；
- 在检查器中查看节点、箭头、来源文件、行列位置和原始内容；
- 检查断链、孤岛、死路、循环和缺失目标；
- 搜索剧情文件、剧本 ID、文案片段和备注，并定位到对应节点；
- 自动布局、拖拽调整、添加备注，以及保存布局和备注；
- 双击节点打开原始 Excel 文件。

工具使用 React + TypeScript、React Flow、`xlsx` 和 `dagre` 实现，并打包为 Windows portable 应用。在当前剧情目录的一次实际扫描中，CanvasTool 读取了 61 个 Excel 文件，生成 90 个节点和 205 条边，并列出 39 个待检查问题。
