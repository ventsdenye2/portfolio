# 知风夜跑

一个单文件交互叙事网页。

## 运行方式
直接双击 `index.html` 即可在浏览器中打开。

## 操作
- 交替按 `A / D`
- 或交替点击鼠标左键 / 右键
- 移动端可交替点击屏幕左右两侧
- 奔跑阶段停下太久会进入第三结局

## 主题
故事不是要求玩家选择“治愈”或“疯狂”，而是在追问：
当爱失去、证明失效、意义暂时缺席时，人是否仍能继续行动；
以及一个人如何在保留亲密需要的同时，不再把自我价值的签发权完全交给他人。
